Getting AWS Credentials
  1. Login to AWS Console
  2. Go to IAM Service → Users
  3. Click on your username or create a new user
  4. Go to Security credentials tab
  5. Click Create access key
  6. Select Application running outside AWS
  7. Copy the Access Key and Secret Key
  8. Important: Save the Secret Key immediately (you won't see it again)

Troubleshooting Common Issues
Invalid Credentials

Check that you copied the correct Access Key and Secret Key from AWS IAM.

Permission Denied

Ensure your IAM user has the required S3, Glue, and Athena permissions.

Region Issues

Make sure you select the correct AWS region where your resources are located.
